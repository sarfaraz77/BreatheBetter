# BreatheBetter App

BreatheBetter is an Android application built using **Kotlin** and **Jetpack Compose**.  
The app displays categorized asthma management tips in an interactive and animated list.

---

## 📱 Features

- Scrollable list using `LazyColumn`
- Expandable cards with animated content
- Animated item entry using `AnimatedVisibility`
- Smooth color transitions using `animateColorAsState`
- Material 3 design components
- Clean composable structure

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio
- State handling using `remember` and `mutableStateOf`
- Basic animations (fadeIn, slideInVertically, animateContentSize)
